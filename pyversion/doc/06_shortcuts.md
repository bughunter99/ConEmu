# 6. 단축키 및 조작 방법

## 6.1 기본 단축키

### 탭 관리

| 단축키 | 동작 |
|---|---|
| **Ctrl+T** | 새 터미널 탭 열기 |
| **Ctrl+W** | 현재 탭 닫기 (마지막 탭이면 앱 종료) |
| **Alt+1** ~ **Alt+9** | 해당 번호의 탭으로 이동 (1번 탭 = Alt+1) |

### 설정

| 단축키 | 동작 |
|---|---|
| **Ctrl+,** | 설정 다이얼로그 열기 |

### 터미널 내 조작

다음 단축키는 터미널 창에 포커스가 있을 때 쉘 프로세스로 전달됩니다.

| 단축키 | 전달 값 | 일반적인 의미 |
|---|---|---|
| **Enter** | `\r` | 명령 실행 |
| **Backspace** | `\x7f` (DEL) | 앞 글자 삭제 |
| **Tab** | `\t` | 자동 완성 |
| **Escape** | `\x1b` | 현재 입력 취소 |
| **Ctrl+C** | `\x03` (ETX) | 현재 프로세스 강제 종료 |
| **Ctrl+D** | `\x04` (EOT) | EOF 전송 (쉘 종료) |
| **Ctrl+L** | `\x0c` (FF) | 화면 지우기 (clear) |
| **Ctrl+Z** | `\x1a` (SUB) | 프로세스 일시 중단 (Unix) |

### 커서 이동 키

| 키 | VT 시퀀스 | 동작 |
|---|---|---|
| **↑** (위 방향키) | `\x1b[A` | 커서 위로 / 히스토리 이전 명령 |
| **↓** (아래 방향키) | `\x1b[B` | 커서 아래로 / 히스토리 다음 명령 |
| **→** (오른쪽 방향키) | `\x1b[C` | 커서 오른쪽으로 |
| **←** (왼쪽 방향키) | `\x1b[D` | 커서 왼쪽으로 |
| **Home** | `\x1b[H` | 줄 맨 앞으로 이동 |
| **End** | `\x1b[F` | 줄 맨 뒤로 이동 |
| **PageUp** | `\x1b[5~` | 위로 스크롤 |
| **PageDown** | `\x1b[6~` | 아래로 스크롤 |
| **Delete** | `\x1b[3~` | 커서 위치 글자 삭제 |
| **Insert** | `\x1b[2~` | 삽입 모드 전환 |

### 기능 키 (F-키)

| 키 | VT 시퀀스 | 비고 |
|---|---|---|
| **F1** | `\x1bOP` | 도움말 (쉘/앱 마다 다름) |
| **F2** | `\x1bOQ` | |
| **F3** | `\x1bOR` | 검색/반복 (bash) |
| **F4** | `\x1bOS` | 편집 (bash) |

> F5~F12는 현재 매핑이 없습니다. 해당 키는 무시됩니다.

## 6.4 단축키 커스터마이징

설정 다이얼로그의 **Keyboard** 페이지에서 단축키를 변경하거나,  
`~/.conemu-py/config.json` 파일의 `keyboard` 섹션을 직접 편집할 수 있습니다.

**예시 — 새 탭을 Ctrl+N으로 변경:**
```json
"keyboard": {
  "new_tab": "Ctrl+N"
}
```

단축키 형식은 Qt의 `QKeySequence` 형식을 따릅니다:
- 수정자: `Ctrl`, `Alt`, `Shift`, `Meta`
- 연결: `+`
- 예시: `"Ctrl+Shift+T"`, `"Alt+F4"`, `"Ctrl+,"`

## 6.5 주의사항

### Ctrl+C 처리

ConEmu-Py에서 **Ctrl+C**는 다음 규칙에 따라 처리됩니다:

- 선택 영역이 없으면 → 쉘에 `\x03` (ETX, 인터럽트 신호) 전송
- 선택 영역이 있으면 → 클립보드 복사 (미구현, 추후 지원 예정)

### 포커스

키보드 입력이 터미널에 전달되려면 **터미널 위젯에 포커스가 있어야** 합니다.  
창 제목 표시줄이나 탭 바를 클릭하면 포커스가 이동될 수 있습니다.  
터미널 영역을 클릭하면 포커스가 터미널로 돌아옵니다.

### 미구현 기능

현재 다음 기능은 구현되지 않았습니다:

- 텍스트 선택 (마우스 드래그)
- 클립보드 복사/붙여넣기 (Ctrl+Shift+C/V)
- 터미널 내 검색 (Ctrl+F)
- 마우스 클릭을 쉘에 전달
